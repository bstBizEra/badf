| Intent | Primary references | Required artifact |
| --- | --- | --- |
| Frame new work | `docs/00`, `docs/01`, `docs/13` | Work package |

| Memory/learning | `docs/04`, `docs/12` | Memory or learning record |

| Release/deploy | `docs/11` | Release packet + gate dossier |
| Operate/close | `docs/12` | Runtime evidence + G13/G14 dossier |

Document numbers refer to filenames in repository `docs/`. Always include `docs/05-evidence-and-provenance.md` for a material claim or gate decision.
